# Rick & Morty Character Explorer

Una aplicación web de una sola página (SPA) diseñada para explorar el universo de la serie Rick and Morty. El proyecto consume datos en tiempo real de una API pública y permite visualizar personajes con un diseño responsivo y funcional.

## 👥 Integrantes
*   **Facundo Bustamante**

## 🚀 Tecnologías Utilizadas
*   **HTML5:** Estructura semántica para mejorar el SEO y la accesibilidad.
*   **CSS3:** Diseño responsivo mediante Flexbox y CSS Grid, incluyendo indicadores visuales de estado.
*   **Vanilla JavaScript (ES6+):** Lógica de programación pura, sin dependencias de frameworks externos.
*   **Fetch API:** Consumo de datos asincrónico mediante `async/await`.
*   **Git & GitHub:** Control de versiones y gestión del flujo de trabajo.
